# Как получить IPA на Windows

Проект собран как исходники Xcode для iPhone. **Здесь в ZIP ещё нет готового IPA**: сборка iOS требует Xcode на macOS. Но исходники можно собрать на GitHub Actions, не покупая Mac.

## Вариант A — сразу потренироваться в IDA (без сборки)

1. Распакуй архив.
2. Открой IDA Pro 9.2.
3. `File > Open` → файл `bin/LicenseCore-arm64.o`.
4. Если будет запрос формата, выбери **Mach-O ARM64**.
5. В **Strings** (обычно `Shift+F12`) найди `2023-12-31T23:59:59Z`.

Это **реальный объектный код ARM64**, взятый из того же C-файла, который используется в iOS-приложении. Это не IPA и не полноценное приложение, но именно подходящий материал для первой тренировки.

## Вариант B — получить настоящий IPA

1. Создай **пустой репозиторий** на GitHub; выбери пустой README или нет — лучше совсем пустой.
2. На Windows открой **PowerShell** в папке с распакованным проектом. Если установлен Git for Windows, введи:

```powershell
git init
git branch -M main
git add .
git commit -m "AtlasLab iOS training app"
git remote add origin https://github.com/ВАШ_ЛОГИН/ИМЯ_РЕПОЗИТОРИЯ.git
git push -u origin main
```

Адрес `origin` замени на адрес **своего** нового репозитория. GitHub может запросить вход в браузере. **Не отправляй никому персональные токены.**

3. Открой репозиторий на GitHub → вкладка **Actions**.
4. Выбери **Build unsigned iOS training IPA**. Если сборка не стартовала автоматически, нажми **Run workflow**.
5. После завершения открой соответствующий запуск → **Artifacts** → скачай `AtlasLab-iOS-lab-files`.
6. В ZIP будут `AtlasLab-UNSIGNED.ipa` и `AtlasLab-arm64-MachO`.
7. Для IDA открой Mach-O сразу, для установки на iPhone подпиши **собственным действующим сертификатом разработчика** через ESign, затем установи.

Если сборка завершится с ошибкой, приложи `build-log` из Artifacts или последние 40 строк журнала `Build arm64 iPhone app` — будем исправлять конкретную ошибку. Работающий IPA не гарантируется до первой успешной сборки.

## После сборки

1. В приложении открой вкладку **Подписка**.
2. Оставь **Учебный PRO** и **Локальная проверка**.
3. Увидишь `PRO НЕАКТИВЕН` и дату `2023-12-31`.
4. Позднее изменим в собственной сборке только год на `2099`, сохраним патч в Mach-O, снова подпишем IPA и сравним поведение.

Режим **Имитация сервера** — это JSON внутри app bundle, не внешний сервер. Он показывает отдельный источник состояния, но не является защищённой серверной лицензией.
